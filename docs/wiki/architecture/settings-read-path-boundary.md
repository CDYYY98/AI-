# 设置读路径边界

## Background

模型厂商配置会同时服务系统设置页、顶部模型选择、桌面客户端启动后的配置恢复，以及管理员排查模型通道。这里的读取路径如果顺手访问远程模型目录、余额接口或本机中转，会把页面打开速度绑定到外部网络和网关状态。对于 `127.0.0.1`、内网地址、自建中转或需要代理的厂商地址，服务端所在机器未必能访问这些地址，读配置时探测它们会造成设置页变慢或误报异常。

## Decision

`GET /api/settings/api-keys` 是本地配置摘要接口，只负责返回已保存的厂商状态、当前模型、API 地址、启用状态、图像模型和内置候选。它不主动请求远程 `/models`，也不做连通性、余额或外部网关探测。

远程模型目录刷新必须通过显式动作触发，例如厂商卡片里的“刷新模型”。连通性和余额检查也应继续留在专门的刷新、测试或诊断入口。

## Current Rule

- 读取模型厂商列表时，内置厂商返回内置模型候选，并合并当前保存或环境变量里的模型。
- 自定义 OpenAI 兼容厂商只返回当前保存的模型名；如果需要发现更多模型，由用户在对应动作中刷新或手动填写。
- `127.0.0.1` 这类地址只对发起请求的机器有效。正式服务端读取配置时不能假设它能访问管理员本机中转。
- 余额查询、模型列表刷新和连通性测试属于显式远程动作，不属于设置页首屏摘要读取。

## Failure Modes

- 如果打开设置页变慢，优先检查配置摘要接口是否重新引入远程 `fetch` 或模型目录枚举。
- 如果本机中转地址导致云端设置页卡住，说明读路径可能又在尝试访问 `127.0.0.1` 或内网地址。
- 如果用户希望更新模型列表，应引导使用刷新模型按钮，而不是在每次读取配置时自动刷新。
